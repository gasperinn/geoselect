GeoSelect — show-results="false" with a custom sidebar

The built-in results list and the "set every stroke's radius to ___" panel are both opt-out (show-results / show-expand-radius). The change event still fires exactly the same either way, so you can build your own results UI — as this page does — without losing any functionality. units="imperial" is also set here, which only affects the (now-hidden) built-in radius panel's unit label.
