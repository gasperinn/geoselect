GeoSelect — opened inside a native <dialog>

<geo-select> stays mounted in the DOM the whole time — only the <dialog> around it opens/closes via .showModal() / .close(). Sizing works correctly because the component watches its own container with a ResizeObserver and calls Leaflet's invalidateSize() whenever that container's box changes size — including the 0×0 → real-size jump that happens the instant a closed <dialog> becomes visible. Because the element is never removed from the DOM, the current selection also survives closing and reopening the dialog.
