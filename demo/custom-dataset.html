GeoSelect — overriding the dataset via .cities

Instead of the bundled ~130k-city dataset, this page hands the component a small, hand-picked list of ten cities via the .cities property. Only those ten can ever be selected — useful if your app only cares about a fixed set of locations (e.g. warehouses, store fronts, regional offices) and shipping the full dataset would be wasted bandwidth.
